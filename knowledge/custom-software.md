# Custom Software

Custom Software is software built around the way a business operates, particularly when off-the-shelf software no longer fits its workflow or business model. ACEVA can assess an existing website or application to determine whether modernization, integration, redesign, maintenance, or further development is appropriate.

## Includes

- SaaS products
- Internal management systems
- Operational dashboards
- Marketplaces and portals
- Custom web applications and integrations
- CRM development and ERP systems
- API development
- SaaS and MVP development

ACEVA’s stated proof example is an operations dashboard with users, permissions, tasks, data, and reporting. Large builds require a written scope, milestones, and acceptance criteria.

ACEVA can start with an appropriately scoped project or MVP. A final scope, architecture, price, and timeline require team review.
